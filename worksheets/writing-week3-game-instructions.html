Writing Worksheet - Week 3

Write Instructions for a Game

Instructions:

Write clear instructions for a game! Choose a game you know how to play and explain how to play it step by step. Include what materials are needed, how to set up the game, the rules, and how to win.

Writing Prompt:

How to Play [Your Game] - Write clear instructions so someone else can learn to play your favorite game!

Game Ideas (Choose one or write about your own game!):

🎲 Board Games

Write instructions for games like Candy Land, Chutes and Ladders, or Memory

🏃‍♂️ Active Games

Write instructions for games like Hide and Seek, Tag, or Simon Says

🎯 Card Games

Write instructions for games like Go Fish, War, or Crazy Eights

🧩 Puzzle Games

Write instructions for games like Tic-Tac-Toe, Connect Four, or Word Games

🎨 Creative Games

Write instructions for games like Charades, Pictionary, or Story Building

🏠 Indoor Games

Write instructions for games like Musical Chairs, Hot Potato, or I Spy

Game Instructions Template:

Game Name: [What is your game called?]

Number of Players: [How many people can play?]

Materials Needed: [What do you need to play?]

How to Set Up: [How do you prepare the game?]

How to Play: [What are the steps?]

Rules: [What are the important rules?]

How to Win: [How does someone win the game?]

Writing Steps:

  1. Start with the name of your game
  2. List what materials are needed
  3. Explain how to set up the game
  4. Write the steps in order (1, 2, 3...)
  5. Include important rules
  6. Explain how to win
  7. Add any special tips or hints

Instruction Words:

  • first
  • next
  • then
  • finally
  • start
  • begin
  • place
  • move
  • take
  • give
  • turn
  • roll
  • draw
  • pick
  • choose
  • count
  • win
  • lose
  • play
  • stop

Writing Tips:

  • Use numbers or bullet points for steps
  • Write in simple, clear sentences
  • Include all the important information
  • Think about what someone who never played would need to know
  • Use words like "first," "next," "then," "finally"
  • Make sure your instructions are easy to follow
